# 军功爵（Military Glory）

适配《骑马与砍杀 II：霸主》`v1.4.8`。

这个模组会记录玩家主力部队中普通士兵的战绩。久经沙场的士兵最终可以被册封为领主，建立自己的贵族家族。

## 安装

1. 安装 `Harmony` 和 `UIExtenderEx`。
2. 将 `MilitaryGlory` 文件夹放入游戏的 `Modules` 目录。（Steam玩家路径为"......\Steam\steamapps\common\Mount & Blade II Bannerlord\Modules"）
3. 在启动器的 Mods 页面中，按以下顺序启用模组：
   - Harmony
   - UIExtenderEx
   - Military Glory

## 怎么玩

1. 正常招募士兵，并带领他们参加战斗。
2. 按 `P` 打开部队界面，选中一个普通兵种。
3. 点击界面弹出下拉区域右下角的按钮，查看该兵种的士兵名单和战绩。
4. 在名单中可以与士兵对话，也可以指定调动某一名士兵。
5. 士兵达到册封要求后，通过对话将其册封为领主。

册封时，你必须是王国领袖，并准备：

- 一座由玩家家族拥有的城镇或城堡；
- `20,000` 第纳尔；
- `500` 影响力。

册封完成后，所选封地会交给这位新领主的家族。

建议在安装、更新或移除模组前备份存档。
